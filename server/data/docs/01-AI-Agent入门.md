# AI Agent 入门：概念与核心能力

AI Agent（人工智能智能体）是一种以大语言模型为核心，能够理解目标、拆解任务、
调用外部工具并持续迭代，直到达成目标的智能程序。

## 什么是 AI Agent

AI Agent 不只是“会聊天”的机器人，它能围绕一个目标自主工作：先理解用户意图，
再把复杂任务拆成可执行的小步骤，需要外部数据时主动调用工具，并在执行过程中
根据结果调整自己的计划。

## AI Agent 的核心能力

### 规划

Agent 会把大目标拆成有序的子任务。例如回答“对比三家供应商报价”，它会先拆出
“获取报价 → 逐项比较 → 汇总结论”等步骤，而不是一次性生成一个没有依据的答案。

### 记忆

Agent 需要记住上下文才能完成多轮任务：

- 短期记忆：当前对话里用户刚说过的需求和约束；
- 长期记忆：跨会话保留的用户偏好、历史结论和可复用经验。

### 工具调用

Agent 可以通过工具连接外部系统：检索知识库、查数据库、调用 API、操作网页等。
工具调用必须带参数校验、超时和权限控制，工具失败时不能把结果伪装成成功。

## AI Agent 与普通聊天机器人的区别

普通聊天机器人通常按预设脚本或单轮问答回复，只能“回答”，不能主动“做事”；
AI Agent 则具备自主性，能规划步骤、使用工具、根据反馈修正，并对结果负责。
这也是“能聊”和“能干活”的分水岭。
