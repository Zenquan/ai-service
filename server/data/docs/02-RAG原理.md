# RAG 检索增强生成原理

RAG（Retrieval-Augmented Generation，检索增强生成）是让大语言模型在生成之前先检索外部资料的技术方案。

## 完整链路

RAG 的完整流程分为八步：文档解析 → 清洗 → 分块 → 向量化 → 存储 → 检索 → 重排 → 注入生成。

第一步文档解析：把 PDF、Word、扫描件等非结构化文档转成可处理的文本。第二步清洗：去掉页眉页脚、乱码、重复空行等噪声。第三步分块：把长文档切成语义完整的片段，常见的做法是段落边界优先、加 overlap 保留上下文。

向量化把文本映射成高维向量，语义相近的文本向量距离近，相似度用余弦相似度计算。向量数据库（如 Qdrant、Milvus、pgvector）负责存储这些向量并提供相似检索。

检索时把问题也向量化，在向量库里找最近邻的 top-K 个片段。重排（rerank）是用更精准的模型把真正相关的片段排到前面。

## 防幻觉设计

RAG 防幻觉的关键是引用校验：正文引用资料必须用 [来源N] 标记，程序校验引用序号是否在资料范围内，防止模型编造不存在的来源。只有"检索 + 生成 + 引用校验"形成闭环，幻觉才能被工程化拦截。
