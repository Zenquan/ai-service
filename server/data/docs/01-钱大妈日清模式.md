# 钱大妈的门店经营模式

钱大妈是一家社区生鲜连锁品牌，核心经营模式是"日清模式"：当日到货、当日清完，不卖隔夜菜。

## 核心特点

日清模式要求门店每晚 21 点前将当日到货的生鲜商品全部售罄。卖不完的菜必须打折清货，不允许留到第二天。这一模式的关键是周转快、损耗低、品质新鲜。

晚市清货是每天最重要的营销节点：18 点开始梯度降价（九折、七折、五折），21 点前必须清完。清货话术强调"倒计时"和"最后 X 份"制造紧迫感。

## 运营要点

- 今日鲜：每天清晨到货的新鲜商品，是吸引客流的核心卖点
- 备货预测：结合天气、节假日、历史销量预测次日备货量
- 损耗管理：隔夜损耗分析，定位问题品类及时段
- 会员触达：会员日清专享优惠，晚间清货提前通知
